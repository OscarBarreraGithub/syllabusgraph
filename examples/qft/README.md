# Quantum field theory course example

This example is being developed as a public demonstration of two courses over
one reviewed knowledge graph. Its intended references are Weinberg volumes I
and II, Peskin–Schroeder, and Schwartz.

**Current state:** reference files have been supplied locally. Course guidance,
source extraction, and scientific review are pending. There is no completed
graph, syllabus, or set of conclusions to use yet.

The eventual public example can contain the reviewed graph, original summaries
and conclusions, bibliography and citations, and QFT I/II course plans.
Textbooks, raw extracted text, quotation-check files, and private work logs are
not part of this example and must not be committed here.

To start your own subject, follow the [generic new-course instructions](../../README.md#create-your-own-course).
The course you create starts empty and contains no assumptions from this example.
Put your references in that project's `materials/` folder and your directions
in `COURSE_GUIDANCE.md`. See [file locations](../../docs/file-locations.md) and
[sharing a course](../../docs/sharing.md).
