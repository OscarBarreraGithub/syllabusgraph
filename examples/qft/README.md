# Quantum field theory example

This example starts with a [public graph collection](../../graphs/subjects/qft/README.md):
one graph per textbook and a shared QFT graph with links back to each book's
treatment. The references are Weinberg volumes I and II, Peskin–Schroeder,
and Schwartz. Graph construction is independent of any particular class.

**Current state:** the first reviewed collection contains 36 concepts across
four textbook graphs and 37 nodes in the shared synthesis, covering 26 printed
pages. The shared graph separates two derivation methods from their common
result. Exact page scopes and review status are recorded in the collection.
These are partial textbook graphs; no complete book or finished course is
claimed. The end human audit remains pending.

The public example contains original graph summaries, source citations,
and review/coverage records. QFT I/II course plans come later. The
[roadmap](../../docs/roadmap.md) records the follow-up task of choosing the
right questions to turn a graph into a course.
Textbooks, raw extracted text, quotation-check files, and private work logs are
not part of this example and must not be committed here.

To start your own subject, follow the [generic new-course instructions](../../README.md#create-your-own-course).
The course you create starts empty and contains no assumptions from this example.
Put your references in that project's `materials/` folder and your directions
in `COURSE_GUIDANCE.md`. For graph-only work, establish source scope first;
audience and scheduling can wait. See [file locations](../../docs/file-locations.md) and
[sharing a course](../../docs/sharing.md).
